Advanced Conditionals

To talk about conditions in technology and automation, we often use alternatives to "If".

1. UNLESS (If ... not)

It means "except if". The verb following 'unless' is usually affirmative.
Unless you save the HTML file, the website will crash.
(If you don't save the HTML file...)

2. AS LONG AS / PROVIDED THAT (Only if)

It emphasizes that one thing will happen only on the condition that another thing happens.
The Google Apps Script will work as long as the code has no bugs.
