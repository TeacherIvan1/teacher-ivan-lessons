Unfinished Time Periods

We use the Present Perfect for actions that happen in a period of time that is not finished yet. If the time is already over, we must use the Past Simple.

Finished vs. Unfinished:

✔️ Finished (Past Simple): yesterday, last week, last month, in 2020.
I ran 5k yesterday.

✔️ Unfinished (Present Perfect): today, this week, this month, this year, so far.
I have run 5k today. (The day is not over yet!)

⚠️ Common Mistake:
Never use the Present Perfect with "yesterday" or "last year".
❌ I have worked a lot yesterday. ➔ ✔️ I worked a lot yesterday.
