Present Simple Passive

We use the Passive Voice when the action is more important than the person doing it, or when we don't know who does the action.

Structure:

Object + am / is / are + Past Participle (V3)

Active: The janitor cleans the classroom.
Passive: The classroom is cleaned (by the janitor).

💡 Remember:
If the object is singular, use is. If the object is plural, use are.
The window is closed. / The computers are turned off.
