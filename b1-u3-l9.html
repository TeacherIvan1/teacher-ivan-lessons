Are you ready?

This worksheet tests everything you have learned in Unit 3. Use this quick reference guide to remember the core structures before you begin:

Conditionals

  • 2nd: If + Past, would + V1
  • 3rd: If + Past Perf, would have + V3
  • Unless: If not
  • Provided that: Only if

Relative & Future

  • Who/That: People
  • Which/That: Things
  • Whose: Possession
  • Future Cont: will be + V-ing
