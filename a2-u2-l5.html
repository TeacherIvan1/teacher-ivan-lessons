Advice vs. Rules

When training, we need to know the difference between a good recommendation to avoid injuries and a strict rule from the coach.

SHOULD / SHOULDN'T (Advice)

We use this to say that something is a good (or bad) idea. It is a recommendation.
Example: You should stretch carefully after running.

MUST / MUSTN'T (Obligation / Rule)

We use this to state strict rules or very important obligations. It is NOT optional.
Example: You mustn't drop the empty barbell. (It's a gym rule!)

⚠️ THE MODAL VERB RULE:
Never use "to" after should/must. Never add "-s" for he/she/it!
✔️ He must train safely.
❌ He musts to train safely.
